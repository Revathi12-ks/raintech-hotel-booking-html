# Raintech Hotel Booking — Vanilla JavaScript

**Stack:** HTML5, CSS3, Vanilla JavaScript. No Node.js, npm, backend, or database is required.

## Run
Open `index.html` directly in Google Chrome (double-click it, or right-click → Open with Google Chrome).

## Features
- Assessment sample rooms
- Check-in cannot be in the past
- Check-out must be after check-in
- One room selection
- Automatic nights and total price
- Clear validation messages
- Bonus guest-capacity filtering
- Bonus sample booked-room date-overlap validation
